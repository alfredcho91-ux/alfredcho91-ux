## 대표 작업 · Trade Journal

**매매 기록을 모으고, 당시 판단과 실제 실행을 돌아보기 위한 트레이드 저널.**

AI 코딩을 활용해 개발 중인 개인 프로젝트. 거래 기록 동기화부터 거래별 차트 복기, 계획·실행 비교, 일일 회고까지 연결하는 도구입니다.

- **거래 기록:** Deepcoin·Binance 읽기 전용 연동과 종료 거래 정리
- **차트 복기:** 진입·청산 지점과 보유 구간을 함께 확인
- **계획과 실행:** 계획 SL/TP·Setup·Mistake 기록, 실제 실행과 비교
- **기록의 축적:** 날짜별 준비·회고를 남기는 Daily Journal, 전략과 규칙을 관리하는 플레이북

현재 개발·검증을 이어가는 프로젝트이며, Windows 배포판은 제한 베타 프리릴리즈 단계. 구현 범위와 검증 한계는 저장소 문서에 기록합니다.

The workflow connects read-only exchange imports, entry and exit chart review, plan-versus-execution comparisons, daily reflections, and a strategy playbook. Development and validation are ongoing; the Windows build is a limited-beta prerelease. The repository documents implementation scope, data assumptions, and validation limits.

My background includes economic and industry reporting, content planning, and hotel operations at a travel company in Canada. Quant-Lab is a separate record of personal market research and analysis experiments.
