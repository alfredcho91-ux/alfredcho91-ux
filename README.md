## GitHub에서 볼 수 있는 작업

이곳의 개발 작업은 **AI 코딩을 활용한 개인 프로젝트**입니다. 취재·운영 경력에 이어, 필요한 도구를 구현하고 수정하는 학습과 실행의 기록을 담고 있습니다.

- **문제를 기능과 화면으로 구체화:** 거래 기록, 차트 복기, 분석 결과를 읽을 수 있는 화면으로 구성합니다.
- **계산과 해석의 조건을 문서화:** 확정봉 기준, 분석 시점, 데이터 출처와 계산의 한계를 프로젝트 문서에 남깁니다.
- **수정과 검토를 이어갈 구조 마련:** 프로젝트별 실행 방법, API 구조, 검증 명령과 보안 관련 설명을 정리합니다.

프로젝트 구성에는 Python·FastAPI, React·TypeScript, SQLite 등을 사용합니다. 구체적인 기능 범위와 실행 조건은 각 저장소의 README를 기준으로 확인할 수 있습니다.
